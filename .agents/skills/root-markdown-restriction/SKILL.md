# Root-Level Markdown File Restriction Skill

## Overview

Enforces strict file organization in the repository root.

## Allowed Root Files

- `README.md`
- `CHANGELOG.md`
- `SUMMARY.md`
- `HISTORY.md`
*Note: All other documentation must reside inside `docs/` or `.agents/`.*
