# Playwright End-to-End Browser Automation Skill

## Overview

Manages headless browser test automation for web portal workflows.

## Features

- End-to-end browser testing uses `playwright` and `pytest-playwright` configured in dev dependencies, with automated E2E integration test suites located in `tests/test_playwright_e2e.py`.
- Playwright browser dependencies for end-to-end testing can be installed using `uv run playwright install chromium`.
- Automates login forms, HttpOnly cookie validation, user registration, and dashboard rendering.
